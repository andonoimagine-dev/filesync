Cara backup Android ke PC via browser
Yang TIDAK bisa dibaca aplikasi ini:
• Android via USB (MTP) — bukan filesystem biasa, browser tidak bisa membacanya
• FTP via "Add a network location" — itu hanya tampilan khusus File Explorer, bukan drive sungguhan, sehingga tidak muncul di folder picker browser
Yang BISA dibaca: drive lokal (C:, D:) dan network drive dengan huruf drive (hasil "Map network drive" via SMB, atau mount RaiDrive/rclone).
1
SMB via WiFi — direkomendasikan ✓ Install LAN Drive (gratis) di Android → jalankan, catat alamat misal \\192.168.1.5. Di Windows: This PC → Map network drive → pilih huruf (misal Z:) → masukkan alamat. Drive Z: adalah drive sungguhan dan bisa dipilih di aplikasi ini. Setup sekali, selanjutnya tinggal konek WiFi yang sama.
2
FTP + RaiDrive (jika tetap mau FTP) FTP Server di Android tetap bisa dipakai, tapi di PC harus di-mount jadi huruf drive pakai RaiDrive (gratis) atau rclone mount — bukan "Add a network location". Setelah jadi drive Z:, baru terbaca di sini.
3
Salin manual via File Explorer Tanpa install apapun: sambungkan USB → File Explorer → salin folder Android ke folder lokal misal D:\Temp\AndroidBackup → pilih folder itu sebagai Sumber di sini.
4
Cloud / Syncthing Google Drive/OneDrive auto-upload dari Android lalu pilih folder sync lokal di PC sebagai Sumber. Atau Syncthing untuk sync dua arah via WiFi tanpa cloud — folder hasilnya dikelola aplikasi ini.
